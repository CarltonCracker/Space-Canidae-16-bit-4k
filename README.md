# Space Canidae 16-bit 4K

This is a fork of Kandowontu's Enhanced PC port to experiment with rendering enhancements geared towards 1440p/4k gaming such as high resolution textures/sprites, replacing sprites with true 3d models, an any other potential timing work to match the original chip timing if needed.  This is achieved with a "modern" renderer that utilizes true 3D geometry for rendering, making it much faster than the standard renderer that, true to the original game, makes many passes per frame to generate an image.

My main focus will be Windows and PCVR (specifically Steam Frame)
